DESCRIPTION

yourname studies computer science at McMaster University and is most at home in the layers people rarely see: operating systems, networks, and the infrastructure everything else runs on. That interest started in 2022 with a Raspberry Pi running two services, and the homelab is now on its third version (see ENVIRONMENT). The plan is a career in security or infrastructure, ideally where the two meet, with plenty of curiosity left over for the rest of the field.

yourname daily-drives Fedora Linux and GrapheneOS and lives as de-Googled a life as possible: free and open-source software first, offline tools where the task allows, and self-hosted services for the rest. The software people depend on should be free to read, change and share.

ENVIRONMENT

yourname runs in a homelab, now on its third version. The rule is to self-host everything possible, to stay in control of personal data and secure as much as possible locally.

CLUSTER
Two Proxmox VE nodes, plus the Raspberry Pi 3B+ from v1, now a QDevice whose tie-breaking vote keeps the cluster in quorum when a node goes down. Caddy, Pocket ID, Vaultwarden, OpenCloud, Immich and Stirling PDF get full VMs; everything else runs in LXC containers to save RAM.
POWER
Everything is on a UPS, including the OpenWrt router and the fiber ONT, so the network and some services stay up through an outage. When the power goes out, NUT shuts down the power-hungry node to stretch the battery while the low-wattage node keeps running. WOLNUT, on the Pi, wakes the big node back up when power returns.
EDGE
A VPS is the only way in from the internet, and only for a select few services. HAProxy passes TLS through without decrypting it, so the VPS never sees plaintext, and sends it over WireGuard to Caddy at home. CrowdSec reads Caddy's logs, and its bouncer on the VPS blocks attackers before they reach the house.
TRANSPORT
VMs and containers talk to each other only through WireGuard tunnels, so nothing else on the network can read the traffic between them.
NETWORK
OpenWrt splits the network into subnets for trusted devices, servers, IoT and guests. Trusted devices can open connections to the servers; the servers can only reply. Internet traffic leaves through a VPN provider.
DNS
AdGuard Home with Unbound blocks ads and known-malicious domains. Split-horizon DNS sends devices at home straight to Caddy, so local traffic never leaves the house, and Unbound's own queries go out through the VPN, so the ISP never sees a lookup. A local NTP server keeps the clocks honest.
ACCESS
Everything that isn't public is reachable only over Tailscale, which runs in its own container and hands traffic to Caddy. Tailnet Lock is on, so no device joins the tailnet unless a trusted device signs it, even if Tailscale's own servers were compromised. Pocket ID handles sign-in with passkeys instead of passwords.
MONITORING
Prometheus collects the metrics and Grafana draws them.
BACKUPS
Anything important is encrypted before it leaves the house, then stored on a Hetzner Storage Box.
