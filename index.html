DESCRIPTION

gureet studies computer science at McMaster University and is most at home in the layers people rarely see: operating systems, networks and the infrastructure everything else runs on. gureet has run a homelab since 2022 and is aiming for security or infrastructure, ideally where the two meet, while staying curious about the rest of the field.

ENVIRONMENT

gureet runs in a homelab, now on its third version. The rule is to self-host everything possible and keep personal data under local control.

CLUSTER
Two Proxmox VE nodes, plus the Pi from v1 as a QDevice whose tie-breaking vote keeps the cluster in quorum when a node is down. Some services get full VMs; the rest run in LXC containers to save RAM.
POWER
Everything is on a UPS, router and ONT included, so the network and the low-wattage node ride out an outage. NUT shuts down the power-hungry node to save battery, and WOLNUT on the Pi wakes it when power returns.
EDGE
A VPS is the only way in from the internet, and only for a select few services. It passes TLS through unopened, so it never sees plaintext, and CrowdSec blocks attackers there before they reach the house. Anubis turns away AI scrapers wherever it won't break anything.
ACCESS
Away from home, everything else is reachable only over Tailscale. Tailnet Lock means no device joins without a trusted device's signature, even if Tailscale's own servers were compromised. Pocket ID handles sign-in with passkeys.
NETWORK
OpenWrt splits trusted devices, servers, IoT and guests into separate subnets; servers can answer trusted devices but never start a connection. VMs and containers talk to each other only over WireGuard, and internet traffic leaves through a VPN provider.
DNS
AdGuard Home and Unbound block ads and known-malicious domains. Split-horizon DNS keeps local traffic inside the house, and Unbound's queries leave through the VPN, so the ISP never sees a lookup. A local NTP server keeps the clocks honest.
BACKUPS
Anything important is encrypted before it leaves the house, then stored on a Hetzner Storage Box.

PROJECTS

kitae

An offline workout journal for Android. Plan your split once as named training days, then pick a day and tick off your sets, with a rest timer. All data stays on the phone. A fork of LooKeR's Kenko with a Material Design interface.

kotlin · android · gplv3sourcereleases

fastfahr

A marketplace for buying and selling German cars, built by a team of four, with photo listings, search by vehicle specs, bookmarks and buyer–seller messages. A React single-page app on a PHP and MySQL back end.

My part: user authentication and profile management.

  • Passwords hashed with bcrypt, and a fresh session ID at every login.
  • Password resets with single-use 256-bit codes that are stored hashed, expire after an hour, and never reveal whether an email has an account.
  • Profile pictures checked by their contents rather than their names, with SVGs refused. I tested it with a disguised PHP script, a PNG named shell.php and an SVG hiding a script; all three were rejected.
  • Prepared statements for every query in the user and reset code, and profile edits that can only touch the signed-in user's own account.

react · php · mysql · team of 4sourcedemo video

wglinkin progress

A lightweight tool for creating, linking and managing WireGuard tunnels between machines on a LAN, so nothing else on the network can read their traffic. It can work across the internet too.

go · wireguard · cli + tuisource
